# Spec: Zoom the panel text with keys

## Design

The intent was approved with its proposals as the answers:

- 75%–200% in steps of 10 points from 100%;
- no persistence across shell restarts;
- the card grows up to the existing cap.

Line numbers are for `1a7587b` (v1.0.1).

1. **Zoom state** (`PipelinesPanel.qml`, root `Item`).
   - `property int zoomPercent: 100` holds the level. The plugin stays loaded
     (`manifest.json:6`, `keepLoaded: true`), so the level survives closing
     and reopening the panel and resets when the shell restarts.
   - Two helpers: `function zf(v) { return Math.round(v * zoomPercent / 100) }`
     for font sizes, and `function zs(v) { return v * zoomPercent / 100 }`
     for layout sizes. `zs` is not rounded, so small spacings don't collapse.
2. **Stepping** (`PipelinesModel.js`). New pure function
   `zoomStep(percent, direction)`:
   - `direction` `+1` gives `Math.min(200, Math.floor(percent / 10) * 10 + 10)`;
   - `-1` gives `Math.max(75, Math.ceil(percent / 10) * 10 - 10)`;
   - `0` gives `100`.

   This produces 100 → 90 → 80 → 75 (clamp) and 75 → 80 → 90 …, and ends at
   200 and 75. It lives in the model so `tests/model.cjs` can test it
   directly.
3. **What scales.** Every `Style.font.*` pixel size in the panel goes through
   `zf`. Every `Style.space(n)` and `Style.spacing.*` value that sizes text,
   rows, indents or padding goes through `zs`. That covers:
   - the card size `Style.space(900)` and `Style.space(680)` (`:250-251`);
   - `Style.spacing.panelPadding` (`:255`);
   - the row heights `Style.space(64)` and `Style.space(40)` and their font
     terms (`:345`);
   - the indents `Style.space(8)` and `Style.space(18)` (`:350-351`);
   - the status icon width `Style.space(18)` (`:355`);
   - `Style.spacing.md` and `Style.spacing.sm` (`:288`, `:352`);
   - the search field height, which already follows its font (`:299`).

   These stay at the theme value, as the intent says:
   - `Style.gapsOut` in the card cap (`:250-251`);
   - `Style.cornerRadius` (`:253`);
   - the border width `Math.max(1, Style.space(2))` (`:254`);
   - `Style.spacing.hairline` (`:332`).

   The card is `Math.min(zs(Style.space(900)), window.width - Style.gapsOut * 2)`,
   and the same for the height. Past the cap the `ListView` shows fewer rows,
   and titles elide as they already do (`Text.ElideRight`).
4. **Keys.** New `function zoomKey(event)`. It returns `true` and changes
   `zoomPercent` when all of these hold:
   - `event.modifiers & Qt.ControlModifier` is set;
   - neither `Qt.AltModifier` nor `Qt.MetaModifier` is set (AltGr reports
     Ctrl+Alt on Linux, so it is excluded too);
   - `event.key` is `Qt.Key_Equal` or `Qt.Key_Plus` (in), `Qt.Key_Minus`
     (out), or `Qt.Key_0` (reset).

   Shift and the keypad modifier are allowed, because `+` needs Shift on many
   layouts. The list handler (`:265`) and the search field handler (`:306`)
   both start with `if (root.zoomKey(event)) { event.accepted = true; return }`.
   `Keys.onPressed` runs before the `TextInput`'s own handling
   (`Keys.priority` defaults to `BeforeItem`), so an accepted zoom key never
   reaches text editing. The query, the selection and the focus stay as they
   were.
5. **Keep the selection in view.** `onZoomPercentChanged` runs
   `Qt.callLater(function() { list.forceLayout(); list.positionViewAtIndex(cursor, ListView.Contain) })`,
   the same call `move()` uses (`:97`).
6. **Indicator.** The footer `Text` (`:404-412`) moves into an `Item` row
   with a second `Text` (`zoomLabel`) anchored right:
   - `zoomLabel` shows `zoomPercent + "%"`, is visible only when
     `zoomPercent !== 100`, and has no elide;
   - the hint text's width is `parent.width - (zoomLabel.visible ? zoomLabel.implicitWidth + Style.spacing.sm : 0)`
     and keeps its `ElideRight`;
   - a cooldown message still replaces only the hint text, so the percentage
     stays visible.
7. **Docs.** Add the three keys to the README key table (`README.md:155-167`)
   and to the key reference in `keybindings.sh`.

## Alternatives rejected

- **A `Scale` transform on the card.** It scales the bitmap, so text renders
  blurry and the card can grow past the screen. The cap would then need a
  separate calculation.
- **Writing `[font] base-size`.** It changes the whole shell, which is the
  problem this issue exists to avoid.
- **Multiplying by 1.1 per step.** It never returns to exactly 100%, and the
  intent fixed added steps.
- **Persisting to `shell.json`.** The intent says no persistence.

## Risks

- **Real key events in the smoke test.**
  - The plan's first step checks whether QtTest's `TestCase.keyClick` works
    inside a plain `quickshell` process. The module is at
    `qtdeclarative-6.12.0/lib/qt-6/qml/QtTest`.
  - If it doesn't, the fallback is `wtype` against the test window.
  - If neither works, the plan stops and reports, rather than calling
    `zoomKey` directly, because the intent forbids that.
- **Keyboard layouts.** Some layouts send `Key_Equal` for `Ctrl+=` and others
  send `Key_Plus` for `Ctrl+Shift+=`. Both are matched. Nothing else was
  tested on non-US layouts.
- **Rounding.** At 75%, the 10 px caption rounds to 8 px. That is the intended
  lower limit.
- **Conflict with #21.** None: #21 is merged, and this spec is written against
  its merge.

## Verification

| Outcome | Test |
| --- | --- |
| Step sequence and clamps | `model.cjs`: `zoomStep` sequences up from 75 and down from 200, and reset |
| Keys in the list | `qml-smoke.py`: real `Ctrl+=` → 110; `Ctrl+Shift+=` → 120; `Ctrl+-` → 110; `Ctrl+0` → 100 |
| Keys in search | `qml-smoke.py`: with the search focused and text `ab` selected, `Ctrl+-` → 90; the text is still `ab`, the selection is unchanged, and the search still has focus |
| Modifiers | `qml-smoke.py`: `Ctrl+Alt+=` and `Super+Ctrl+=` leave the zoom unchanged |
| Scaling | `qml-smoke.py`: at 150, a body `Text` has `pixelSize === Math.round(Style.font.body*1.5)`, and the hairline and radius are unchanged |
| Cap | `qml-smoke.py`: at 200, `card.width <= window.width - 2*Style.gapsOut` |
| Selection in view | `qml-smoke.py`: after zooming in to 200 with the cursor on the last row, that row's delegate is inside the list viewport |
| Indicator | `qml-smoke.py`: at 120 with a cooldown set, `zoomLabel.visible` is true, its text is `120%`, and it is not elided |
| Survives close/open | `qml-smoke.py`: zoom 130, close, open: still 130 |

Release: `manifest.json` `version` becomes `1.1.0`, a new feature.
