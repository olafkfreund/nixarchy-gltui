## Approved decisions (from the spec)

### Helper

`job(row)` adds three fields:
- `failure_reason`: `plain()` of a string, else `""`;
- `duration`: an `int` or `float` (not a `bool`) that is finite and
  `>= 0`, else `None`;
- `queued_duration`: the same rule as `duration`.

`pipeline()` is unchanged.

### Raw row fields

Every row keeps all of today's fields, and `info` is still the rebuild-time
text. The new fields:

| Kind | Field | Source | Missing |
|---|---|---|---|
| `repo` | `checked` | `repo.checked` | `""` |
| `run` | `started` | `run.started_at \|\| run.run_started_at` | `""` |
| `run` | `ended` | `run.completed_at`, or `run.updated_at` when `run.status === "completed"` (exactly the inputs `duration()` uses today) | `""` |
| `run` | `finished` | `run.completed_at` only | `""` |
| `run` | `fetched` | `detail.updated` | `""` |
| `stage` | `started`, `ended` | `stage.span.started_at`, `stage.span.completed_at` | `""` |
| `stage` | `done`, `total` | the completed-job count, `stage.jobs.length` | numbers |
| `job` | `started` | `job.started_at` | `""` |
| `job` | `ended`, `finished` | `job.completed_at` | `""` |
| `job` | `complete` | `job.status === "completed"` | `false` |
| `job` | `serverDuration` | `job.duration` | `null` |
| `job` | `queued` | `job.queued_duration` | `null` |
| `job` | `reason` | `job.failure_reason` | `""` |

### Run subtitle

It drops the embedded `" · jobs fetched HH:MM:SS UTC"`, and uses
`shortRef(run.head_branch)` instead of the raw ref. Everything else is
unchanged.

### Functions (ES5)

- **`shortRef(ref)`:** `/^refs\/merge-requests\/(\d+)\/(head|merge|train)$/`
  becomes `"!" + N`. Anything else is returned unchanged.
- **`runMatches(run, q)`:** also searches `shortRef(run.head_branch)`.
- **`ago(iso, now)`:** a missing or invalid time gives `""`. Otherwise, with
  `s = floor((now - t) / 1000)`:

  | Seconds | Text |
  |---|---|
  | `s < 10`, or a future time | `just now` |
  | `s < 60` | `Ns ago` |
  | `s < 3600` | `Nm ago` |
  | `s < 86400` | `Nh ago` |
  | otherwise | `Nd ago` |

  Values always round down.
- **`seconds(n)`:** the formatting that `duration()` uses (`45s`, `1m 2s`,
  `1h 5m`). `duration()` calls it, with identical output.
- **`reasonText(code)`:**

  | Code | Text |
  |---|---|
  | `script_failure` | `script failure` |
  | `runner_system_failure` | `runner error` |
  | `stuck_or_timeout_failure` | `timed out` |
  | `job_execution_timeout` | `timed out` |
  | `api_failure` | `API error` |
  | `missing_dependency_failure` | `missing dependency` |
  | `runner_unsupported` | `runner unsupported` |
  | `scheduler_failure` | `scheduler error` |
  | `data_integrity_failure` | `data error` |
  | `unknown_failure` | `unknown failure` |

  Any other code has its underscores replaced with spaces, and `""` gives
  `""`.
- **Live duration:**
  `duration({started_at: row.started, completed_at: row.ended, status: row.ended ? "completed" : ""}, now)`,
  or the equivalent. It counts up while `ended` is empty.
- **Job duration:** `row.complete` with a numeric `serverDuration`, `0`
  included, gives `seconds(Math.round(serverDuration))`. Otherwise use the
  live duration.
- **`infoText(row, now)`:** parts are joined with `" · "`, and empty parts
  are dropped.

  | Kind | Parts |
  |---|---|
  | `repo` | `row.info`; then `"checked " + ago(row.checked, now)`, only when `row.info` ends with `running` and `ago()` is non-empty |
  | `run` | `row.status`; the live duration; `ago(row.finished, now)` |
  | `stage` | `row.status`; `done + "/" + total + " jobs"`; the live duration |
  | `job` | `row.status`; `reasonText(row.reason)`, only when the status is `failed` or `allowed to fail`; the job duration; `"queued " + seconds(round(queued))`, only when `queued > 0`; `ago(row.finished, now)` |
  | `more`, `message`, other | `row.status + (row.info ? " · " + row.info : "")`, today's expression |
- **`subtitleText(row, now)`:** `row.subtitle`, plus
  `" · jobs fetched " + ago(row.fetched, now)` for a `run` row when
  `ago()` is non-empty.
- **`shownFields`:** adds `checked`, `started`, `ended`, `finished`,
  `fetched`, `done`, `total`, `complete`, `serverDuration`, `queued` and
  `reason`.

### Panel

- The info `Text` uses `text: Model.infoText(modelData, root.now)`.
- The subtitle `Text` uses `text: Model.subtitleText(modelData, root.now)`.
  Its `visible`, and the row height, still test `modelData.subtitle`.
- `open()` sets `root.now = Date.now()` first.
- Nothing else changes.
