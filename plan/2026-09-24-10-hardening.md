# Plan: Harden edge cases, add package metadata and CI

Approved decisions (from the spec):

- No host allow-list. CI on GitHub Actions, x86_64-linux only.
- Rate-limit cooldown capped at one hour from the reply.
- Reply data shape checked in `Polling.complete`: a plain object for `run`,
  an array for other kinds. A bad reply becomes
  `{error:"GitLab helper returned invalid data", errorType:"network"}`.
- `http_reply` reads further header blocks only after a 1xx status. 3xx is an
  error: `errorType` `network`, message
  "GitLab redirected the request; the project may have moved".
- `menu.py` `session_tree` skips malformed entries.
- Package `meta`: description, homepage, MIT license, Linux platforms.
- No smoke tests for `openBrowser` or a garbled reply, no redirect following,
  no CI caching.

## Steps

1. `Polling.js` `complete`:
   - Directly after `if (!t) return false;` add
     ```js
     var bad=reply.data===null || typeof reply.data!=="object" || Array.isArray(reply.data)!==(t.kind!=="run");
     if (!reply.errorType && !reply.error && bad) reply={error:"GitLab helper returned invalid data",errorType:"network"};
     ```
   - Replace `s.cooldown=Math.max(s.cooldown,deadline);` with
     `s.cooldown=Math.max(s.cooldown,Math.min(deadline,now+3600000)); // ponytail: 1h cap, a real longer limit just 429s again`.

   `tests/polling.cjs`, after the `limited` block:
   - A fresh state gets a rate reply with `retryAt: 1000 + 365*86400000` at
     `now=1000` → `cooldown === 3601000`.
   - A fresh state gets a `summary`/`catalogue` reply (first `next()`) with
     `data:null` → `complete` returns true, `s.error` is the invalid-data
     message, and the task's `due > now`.
   - A `run` task (created with `polling.select` + expanded run, or `ensure`
     as the existing tests do) gets `data:[]` → same message.

   → verify `node tests/polling.cjs` exits 0.
2. `gitlab.py`:
   - `http_reply`: `while text.startswith("HTTP/"):` →
     `while text.startswith("HTTP/") and (status is None or status < 200):`.

     `if status < 300:`; `if status >= 400 or code:` → `if status >= 300 or code:`;
     after the `status in (403, 404)` branch add
     `elif 300 <= status < 400: result.update(errorType="network", error="GitLab redirected the request; the project may have moved")`.

   `tests/test_gitlab.py`:

     status 200, headers `{"a": "b"}`.

     `("HTTP/2.0 301 Moved\nLocation: x\n\n", "", 0)` → `errorType`
     `"network"`, and the error is the redirect message.
   - `main()`, with `sys.argv` patched to `["gitlab.py", "page", "{}"]`,
     `read_page` patched to raise `gitlab.DeadlineExceeded()`, and stdout

   → verify `PYTHONPATH=. python3 -m unittest tests.test_gitlab` passes.
