# Plan: Help, copy, jump, close and next-failure keys

Self-contained. Branch `feat/29-keys`, based on `0bca0e0` (v1.4.0). Line
numbers are for that commit; match on the quoted code. `Polling.js` must not

## Approved decisions (from the spec)

### Helper

`pipeline(row)` adds `sha`: `row["sha"]` when it is a `str` matching
`[0-9a-f]{40}` or `[0-9a-f]{64}` (use `re.fullmatch`), otherwise `""`.
`display_title` is unchanged.

### Model

- A `run` row gets `sha: run.sha || ""`. Its `stage` and `job` rows get the
  same value. `repo`, `more` and `message` rows get no `sha` field. `sha` is
  added to `shownFields`.
- `nextFailure(rows, cursor)`:
  - It checks the rows after `cursor` in order, wrapping to the start, and
    checks `cursor`'s own row last.
  - It returns the first index whose `kind` is `run`, `stage` or `job`
    and whose `status === "failed"` exactly, or `-1` when there is none
    (including an empty list).
- `copyText(row, what)`, where `what` is `"url"` or `"sha"`, returns:

  | Case | Result |
  |---|---|
  | `url` and `row.url` | `{text: row.url, label: "Copied URL"}` |
  | `url`, no `row.url` | `{text: "", label: "Nothing to copy"}` |
  | `sha` and `row.sha` | `{text: row.sha, label: "Copied " + row.sha.slice(0, 8)}` |
  | `sha`, no `row.sha` | `{text: "", label: "No commit for this row"}` |
  | `row` null | `{text: "", label: "Nothing to copy"}` |

### Panel

**Keys,** in the list handler, after the zoom check:

1. **Help open:**
   - `?` (by `event.text`), Esc or `q` closes help;
   - ↓ / `j` scroll down one line and ↑ / `k` up one line;
   - Page Down / Up scroll by the visible height, clamped;
   - every other key is accepted and ignored.

   Zoom keeps working, because it is checked first.
2. **Otherwise, with no Ctrl, Alt or Super held:**
   - `event.text === "?"` → `helpOpen = true`. This is checked before the
     `/` branch.
   - `Key_Y` → `copy("url")`, or `copy("sha")` with Shift.
   - `Key_G` → `move(-entries.length)`, or `move(entries.length)` with
     Shift.
   - `Key_Q` without Shift → `close()`.
   - `Key_E` without Shift → `nextFailure()`.

   The existing keys stay as they are.

The search field's handler is unchanged.

**`nextFailure()`:**
- `i = Model.nextFailure(entries, cursor)`.
- If `i >= 0`: set `cursor`, call `list.positionViewAtIndex(i, ListView.Contain)`,
  then `selectionChanged(false)`, as `move()` does.
- Otherwise: `notify("No failures in the list")`.

**Copy:**
- `property var copyCommand: ["wl-copy", "--"]`; `copySerial`,
  `copyStarted`, `copyLabel`.
- `copy(what)`:
  1. Call `Model.copyText(current, what)`.
  2. If its text is empty, `notify(label)`.
  3. Else, if `copyProc.running`, ignore the key.
  4. Else set:
     - `copyStarted = false`;
     - `copyLabel = label`;
     - `copyProc.serial = copySerial`;
     - `copyProc.command = copyCommand.concat([text])`;
     - `copyProc.running = true`.
- `Process { id: copyProc; property int serial }`:
  - `onStarted: copyStarted = true`;
  - `onExited(code)`: if `serial === root.copySerial`,
    `notify(code === 0 ? copyLabel : "Copy failed")`;
  - `onRunningChanged`: if `!running && !copyStarted && serial === root.copySerial`,
    `notify("Copy failed")`. This is the missing-binary case: Quickshell
    0.3.1 emits neither `started` nor `exited`.

**Notice:**
- `property string notice`, and `Timer { id: noticeTimer; interval: 2000; onTriggered: notice = "" }`.
- `notify(t)` sets `notice = t` and calls `noticeTimer.restart()`.

**Footer `hint.text`:**

```
root.notice || root.cooldownText || (root.filtering ? searchHint : listHint)
```

- `searchHint`: `↑↓ select  Enter open  Tab navigate  Esc clear`.
- `listHint`:
  `↑↓ move  ←→ expand  g/G ends  / search  e failure  y/Y copy  o GitLab  ? help  q close`.

**Help overlay:**
- A `Rectangle` in the `keys` item, after the `Column` so it draws on top.
  It fills `keys`, uses `color: Commons.Color.menu.background`, and has
  `visible: root.helpOpen`.
- At its top, a caption `Text`: `? or Esc to close`. Under it, a
  `Flickable` (`clip: true`) fills the rest. It holds one plain `Text`:
  - `width` is the `Flickable`'s width;
  - `wrapMode: Text.Wrap`;
  - `font.pixelSize: root.zf(Style.font.body)`, menu family and text
    colour;
  - `text: root.helpText || "Help unavailable — see the README"`.

  `contentHeight` is the text's `implicitHeight`.
- The overlay takes no focus.
- `helpText` is loaded once, on the first open, by
  `Process { command: ["bash", root.localPath("keybindings.sh"), "--print"]; stdout: StdioCollector }`:
  on exit 0, `helpText` is the trimmed output.

**`close()`** adds:
- `helpOpen = false`;
- `notice = ""`;
- `noticeTimer.stop()`;
- `copySerial++`.

**Test hooks:**
- `readonly property Item helpItem` (the overlay);
- `readonly property Item helpFlick` (the `Flickable`);
- `readonly property alias footerHint: hint.text`;
- `copyCommand`, `notice`, `helpOpen` and `helpText` as plain properties.

### Key list and docs

- `keybindings.sh`, after the `o → …` line:
  ```
  y → Copy the selected row's GitLab URL
  Shift + Y → Copy the pipeline's commit SHA
  g / G → First or last row
  e → Next failed pipeline, stage or job
  ? → Show or hide this help in the panel
  q → Close the panel
  ```
- `README.md`:
  - the same rows in the Keyboard table;
  - Requirements `:11` reads: `- Python 3, `xdg-open` for the browser
    shortcut, and `wl-copy` (wl-clipboard) for the copy keys.`;
  - after the table, one sentence: `e` only looks at rows already shown,
    and never opens a pipeline.
