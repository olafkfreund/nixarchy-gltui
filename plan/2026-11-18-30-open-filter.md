## Approved decisions (from the spec)

### Model: `openFilter(payload, panelHost)` in `PipelinesModel.js`

Returns `{filter: <string or null>, notice: <string>}`, always with both
properties. No exception escapes.

1. **Payload type:**
   - A string payload is `JSON.parse`d inside `try`. A parse failure gives
     `{filter: null, notice: ""}`.
   - Any other payload is used as it is.
2. **Object check:** it must be a non-null, non-array object; otherwise
   `{null, ""}`.
3. **`filter`:**
   - It must be a string.
   - Remove `/[\u0000-\u001f\u007f-\u009f]/g`, then trim.
   - Its length must then be 1–200. Otherwise `{null, ""}`: a longer filter
     is rejected, not truncated.
4. **`host`, when the key is present** (`"host" in value`):
   - It must be a non-empty string; otherwise `{null, ""}`.
   - Compare `host.toLowerCase()` with
     `panelHost.replace(/:[0-9]+$/, "").toLowerCase()`.
   - **On a mismatch:**
     `{filter: null, notice: "Repository is on " + shown + "; this panel shows " + panelHost}`.
     `shown` is the host with the same control characters removed, cut to
     100 characters.
5. **Otherwise:** `{filter: cleaned, notice: ""}`.

### `menu.py`

- **`remote(url)`** returns `(host, path)` or `None`. Strip whitespace
  first.
  - **URL form:** for `ssh://`, `http://` and `https://`:
    - use `urllib.parse.urlsplit(url)` inside `try`; a `ValueError` gives
      `None`;
    - the host is `.hostname`, and must not be empty;
    - the path is `.path`;
    - any other `scheme://` gives `None`.
  - **SCP form:** when the URL has no `://`, use
    `re.fullmatch(r"(?:[^@/\s]+@)?([^@/:\s\[\]]+):([^/].*)", url)`.
    - The host is group 1, lower-cased, and the path is group 2.
    - A bracketed host, or a path starting with `/`, does not match, so
      gives `None`.
  - **Path:**
    1. Strip leading and trailing `/`.
    2. Remove one trailing `.git`.
    3. Reject it if it contains whitespace or `%`.
    4. Split it on `/`. It needs at least 2 segments, none of them `""`,
       `.` or `..`.
- **`main()` and `open`:**
  - Accept `["open"]` and `["open", FILTER]`. The usage text is
    `menu.py [keys|toggle|register|open [FILTER]]`.
  - **With `FILTER`:** the payload is `{"filter": FILTER}`.
  - **Without it:** run
    `subprocess.run(["git", "remote", "get-url", "origin"], capture_output=True, text=True, timeout=5, check=False)`.
    - `OSError` or `subprocess.TimeoutExpired` count as no remote.
    - Exit 0 with a parsed remote: `{"filter": path, "host": host}`.
    - No remote: `{}`, and stderr gets
      `GitLab Pipelines: no Git origin remote here`.
    - Unparsed remote: `{}`, and stderr gets
      `GitLab Pipelines: unsupported Git remote: <url>`.
    - Exit code 0 in every case.
  - **Command:**
    `["omarchy-shell", "shell", "summon", "olafkfreund.gitlab-pipelines", json.dumps(payload)]`,
    through the existing `session_tree()` / `os.execvp` path.
  - **Ordering:** the remote lookup runs before `quickshell list`, in the
    current directory.

### Panel (`PipelinesPanel.qml`)

- **New properties:** `property bool configured: false` and
  `property var pendingOpen: []`.
- **`applyOpen(payload)`:**

  ```qml
  function applyOpen(payload) {
      var request = Model.openFilter(payload, host)
      if (request.filter !== null) {
          helpOpen = false
          notice = ""; noticeTimer.stop()
          if (filterText === request.filter) { rebuild(true); selectionChanged(false) }
          else filterText = request.filter
      }
      if (request.notice) notify(request.notice)
  }
  ```
- **`open(payload)`:** after `opened = true` and before
  `selectionChanged(true)`:

  ```qml
  if (configured) applyOpen(payload)
  else pendingOpen = pendingOpen.concat([payload])
  ```
- **`configure(text)`:** at its end, in both the `try` path and the
  `catch` path, call `markConfigured()`.
- **`markConfigured()`:**
  - if `configured` is already true, return;
  - set `configured = true`;
  - take `pendingOpen` and set it to `[]`;
  - call `applyOpen` on each queued payload, in order.
- **`FileView`:** add `onLoadFailed: root.markConfigured()`.
- **Test hooks:** `configured` and `pendingOpen` stay plain properties.
