### `menu.py trace HOST PROJECT JOB`

- Module constant:

  ```python
  TRACE = 'glab ci trace "$1" -R "$2"; printf "\\nPress Enter to close. "; read -r _'
  ```

- A helper that loads `gitlab.py` from `menu.py`'s directory:

  ```python
  def gitlab_rules():
      spec = importlib.util.spec_from_file_location("gitlab_rules", Path(__file__).with_name("gitlab.py"))
      module = importlib.util.module_from_spec(spec)
      spec.loader.exec_module(module)
      return module
  ```

- `trace(host, project, job)`:
  - `rules = gitlab_rules()`; `rules.host_name(host)`;
    `rules.project_path(project)`; `re.fullmatch(r"[1-9][0-9]{0,18}", job)`
    or `raise ValueError("Invalid job")`;
  - `command = ["omarchy-launch-tui", "--app-id=org.omarchy.gitlab-trace", "sh", "-c", TRACE, "sh", job, f"https://{host}/{project}"]`;
  - `proc = subprocess.Popen(command, start_new_session=True, stdin=subprocess.DEVNULL, stdout=subprocess.DEVNULL, stderr=subprocess.DEVNULL)`;
  - `try: code = proc.wait(timeout=2)` / `except subprocess.TimeoutExpired: return 0`;
  - `code == 0` → return 0; else
    `raise RuntimeError(f"terminal launcher failed (exit {code})")`.
- `main()`: as its first branch inside the `try`,
  `if args and args[0] == "trace":` → if `len(args) != 4` raise the usage
  `ValueError`, else `return trace(*args[1:])`. This runs before the usage
  check and before `quickshell list` (`menu.py:162`). The usage text
  becomes `Usage: menu.py [keys|toggle|register|open [FILTER]|trace HOST PROJECT JOB]`
  in both places it appears (`menu.py:141` and `tests/test_menu.py:97`).
- The existing `except (OSError, ValueError, RuntimeError, subprocess.SubprocessError)`
  prints `GitLab Pipelines: <error>` and returns 1 for every failure.

### Panel (`PipelinesPanel.qml`)

- Properties: `property var traceCommand: ["python3", localPath("menu.py"), "trace"]`,
  `property bool traceStarted: false`, `property int traceSerial: 0`.
- `function trace()`:

  ```qml
  function trace() {
      if (!current || current.kind !== "job" || !current.job) { notify("Select a job to open its log"); return }
      if (traceProc.running) return
      traceStarted = false
      traceProc.serial = traceSerial
      traceProc.command = traceCommand.concat([host, current.repo, current.job])
      traceProc.running = true
  }
  ```

- `close()`: add `traceSerial++` next to `copySerial++`
  (`PipelinesPanel.qml:145`).
- Next to `copyProc` (`:455-464`):

  ```qml
  Process {
      id: traceProc
      property int serial: 0
      onStarted: root.traceStarted = true
      onExited: function(code) {
          if (serial !== root.traceSerial) return
          if (code === 0) root.close()
          else root.notify("Could not open a terminal")
      }
      // Quickshell 0.3.1: a missing binary emits neither started nor exited, only running=false.
      onRunningChanged: if (!running && !root.traceStarted && serial === root.traceSerial) root.notify("Could not open a terminal")
  }
  ```

- Key: after the `p` branch in the `plain` chain:
  `else if (plain && event.key === Qt.Key_T && !shift) root.trace()`.
- `listHint`: insert `t log  ` after `p pin  `.
